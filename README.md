# Клипы — короткие видео в Telegram

Мини-приложение с вертикальной лентой: свайп вверх/вниз, лайки, комментарии, подписки, загрузка роликов через чат с ботом и донат в Telegram Stars. Своё название и оформление, без бренда TikTok.

Стек: Python 3.12, aiogram 3, FastAPI, SQLite (SQLAlchemy + aiosqlite). Фронтенд — один HTML/CSS/JS без сборки (`webapp/`).

```
backend/   main.py, bot.py, api.py, service.py, auth.py, db.py, seed.py
config/    prices.json (буст и подарки в Stars)
webapp/    index.html, style.css, app.js
media/     демо-ролики (оригинальные абстрактные клипы, не чужой контент)
tests/     тесты ленты, антифрода initData и оплат
screens/   скриншоты
```

## Как это работает

- **Лента.** Полноэкранные ролики, свайп с привязкой к кадру. Автоплей без звука, тап включает звук, повторный тап ставит на паузу. Следующий ролик предзагружается. Двойной тап — лайк с анимацией сердца.
- **Вкладки.** «Рекомендации» (свежесть + лайки/просмотры, буст поднимает вверх) и «Подписки».
- **Профиль.** Имя и аватар из Telegram, сетка роликов, подписчики, кнопка «Подписаться».
- **Загрузка.** Пользователь присылает видео боту в личку (можно с подписью). Бот сохраняет `file_id`, а сервер стримит файл через `getFile`. В приложении кнопка «Загрузить» открывает чат с ботом.
- **Модерация.** Кнопка «Пожаловаться». Админ (`ADMIN_IDS`) удаляет ролик командой `/delete ID` или из меню «Ещё». Автор может удалить свой.
- **Stars.** «Буст в рекомендации» — 25 ⭐ на 24 часа (только свой ролик). Подарки автору: огонь / сердце / алмаз / корона. Оплата через инвойс XTR, мы только записываем перевод.

## Лимиты Telegram и Render

- Bot API отдаёт файлы боту **только до 20 МБ**. Более тяжёлые ролики бот вежливо отклоняет. Длина — до 90 секунд.
- На **бесплатном плане Render** сервис засыпает после ~15 минут без трафика (первый заход будет долгим), а **SQLite обнуляется** при каждом деплое и часто при рестарте.
- Сами видео живут у Telegram (`file_id` не пропадает), но **метаданные в нашей базе** (кто автор, лайки, комментарии, бусты) при обнулении пропадают. Ролики из ленты как будто «исчезают», пока их не зальют заново.

Как не терять данные: подключить диск Render (`DB_URL=sqlite+aiosqlite:////data/clips.db`) на платном плане или переехать на маленький VPS / Postgres.

## Локальный запуск

```bash
cp .env.example .env        # для локалки хватит DEV_MODE=1, токен не обязателен
python3 -m venv venv && . venv/bin/activate
pip install -r requirements.txt
python -m pytest
DEV_MODE=1 SEED_DEMO=1 RUN_BOT=0 python -m backend.main
```

Открой `http://localhost:8080/?uid=643246726` в браузере. В проде `DEV_MODE=0` обязательно.

С ботом (long polling): заполни `BOT_TOKEN`, `BOT_USERNAME`, `WEBAPP_URL` и запусти без `RUN_BOT=0`. Если заданы `WEBHOOK_SECRET` и HTTPS `WEBAPP_URL`, включается webhook `/tg/<секрет>`.

## Деплой на Render

1. Репозиторий: `https://github.com/ivan60443-ui/clips-tg` (этот проект, не трогаем `raby-tg-game`).
2. Новый Web Service, runtime Python, build `pip install -r requirements.txt`, start `python -m backend.main`, план Free.
3. Переменные: `BOT_TOKEN`, `BOT_USERNAME=Districtt13bot`, `WEBAPP_URL=https://<сервис>.onrender.com`, `WEBHOOK_SECRET` (случайная строка), `ADMIN_IDS=643246726`, `DEV_MODE=0`, `SEED_DEMO=1`, `APP_SHORT_NAME=clips`.
4. После деплоя бот сам ставит webhook, кнопку меню «Открыть», имя «Клипы», описание и команды.
5. В @BotFather стоит обновить Mini App URL на новый адрес (`/mybots` → Bot Settings → Configure Mini App). По желанию `/newapp` с коротким именем `clips` и `/setinline` с подсказкой «поделиться роликом…».

Игру «Рабы» этот репозиторий не перезаписывает: старый код остаётся в `raby-tg-game` и в папке `/workspace/raby-tg`. Чтобы вернуть игру, достаточно снова направить сервис Render на тот репозиторий и поменять webhook.

## Команды бота

- `/start` — открыть ленту
- `/upload` — как выложить ролик
- `/help` — справка
- `/stats` — статистика (админ)
- `/delete ID` — скрыть ролик (админ)

Админ: Telegram ID `643246726`.
